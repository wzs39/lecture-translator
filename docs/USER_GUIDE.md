# Lecture Translator 使用手册

一个为大学生课堂场景设计的中文实时翻译 + 笔记工具：

```
教授讲课 ──> Windows 实时字幕（英语，系统级高质量识别）
            └─> 字幕桥（bridge）读字幕 ──> 本地/云端 AI 翻译成中文
                  └─> 网页显示双语字幕 + 自动保存到课程
                        └─> 课堂问答 / 术语表 / AI 整理 / 分类总结
```

你只需要开着 Windows 实时字幕听讲，剩下的事（翻译、记录、整理）都由这个工具自动完成。

---

## 一、快速开始（5 分钟上手）

### 第 1 步：安装（只需一次）

1. 拿到项目文件夹后，**双击 `install.bat`**（不需要管理员权限）。
2. 安装完成后，桌面会出现 **「Lecture Translator」** 快捷方式。
3. 如果桌面上没有捷径，也可以双击项目里的 **`LectureTranslatorLauncher.exe`**，或按「手动运行」方式启动。

### 第 2 步：启动

- **方式 A（推荐）**：双击桌面快捷方式 → 点击 **启动**。

  启动器会自动：启动 Docker Desktop → 拉起翻译服务 → 最小化启动字幕桥 → 打开网页 `http://localhost:8000`。

- **方式 B（手动）**：
  1. 打开 Docker Desktop；
  2. 双击 `start.bat`（自动等待服务就绪并打开网页）；
  3. 双击 `start-captions.bat`（启动字幕桥，首次运行会在 `bridge/.venv` 自动创建隔离环境）。

> 首次启动需要下载模型，视网速可能需要几分钟，之后每次都是秒起。

### 第 3 步：打开 Windows 实时字幕

1. 按 **`Win + Ctrl + L`** 打开实时字幕窗口（也可以点网页 ③ 区的「打开实时字幕」按钮）。
2. **保持字幕窗口在屏幕上可见**——字幕桥通过读取这个窗口的文字工作，最小化没关系，但不要关掉它。
3. 回到网页，② 服务状态处应显示 **🟢 字幕桥在线**。

### 第 4 步：新建课程并开始听课

1. 在网页 ① 课程区输入课程名称（如“生物化学”），可填分类（如“生物学”）。
2. 点击 **新建课程**。
3. 开始听课。字幕流面板会实时显示 **原文 + 中文翻译**，并自动保存到这门课。

## 二、界面分区说明

网页从上到下分六个区域：

```
┌────────────────────────────────────────────────────┐
│ ① 课程       课程名 + 分类 + 新建课程               │
│ ② 服务状态   服务灯 · 字幕桥三色灯 · 检查服务        │
│ ③ 文字来源   实时字幕（英语）/ 浏览器语音识别（芬兰语）│
├──────────────────────────┬─────────────────────────┤
│ ④ 字幕流                 │ ④ 课堂 AI 问答与笔记      │
│   · 实时双语字幕          │   · 问 AI                │
│   · 导出 TXT/SRT/Word    │   · 提取术语 · AI 整理    │
│                          │   · 我的笔记 · 术语表     │
├──────────────────────────┴─────────────────────────┤
│ ⑤ AI 服务设置   本地 Ollama（默认） + 云端 AI（可选） │
│ ⑥ 存储管理     课程归档 · 分类 · AI 总结 · 搜索 · 统计│
└────────────────────────────────────────────────────┘
```

### ① 课程

- 输入课程名和分类 → **新建课程**。之后所有字幕、笔记、术语都自动归入该课程。
- 右上角显示当前课程名；没有课程时显示「未创建」。
- **上传讲义（PDF / Word / PPT）**：把老师的课件或讲义传上来，AI 会读出其中的文字，用它来**纠错并补充**字幕翻译——比如老师口头的专有名词、公式、人名在无声或有噪声时字幕没抓到，AI 会按讲义里的正确写法补齐，而不是凭空瞎猜。支持 `.pdf` `.docx` `.pptx` `.txt` `.md`，同名文件覆盖，点 × 删除。
  - 注意：扫描版 PDF（纯图片，无文字层）提取不出文字，会提示“no readable text”；请用可选中文字的 PDF。

### ② 服务状态（诊断第一眼）

| 显示 | 含义 | 怎么办 |
|---|---|---|
| 🟢 字幕桥在线 | 正常，正在读取字幕 | 无需操作 |
| 🟡 字幕桥等待字幕窗口 | 桥活着，但没找到字幕窗口 | 按 `Win+Ctrl+L` 打开实时字幕 |
| 🔴 字幕桥离线 | 桥没在运行 | 双击 `start-captions.bat` 重启；或临时用 ③ 浏览器语音识别 |
| 红色警告条（页面顶部） | D 盘剩余不足 20GB | 见 FAQ「D 盘容量报警」 |

- **检查服务**按钮：立即检测翻译服务是否就绪（Ollama + 模型）。

### ③ 文字来源（关键！）

- **英语讲座**：用 **Windows 实时字幕**（识别质量最高）。保持字幕窗口可见。
- **芬兰语等实时字幕不支持的语言**：用 **🎤 浏览器语音识别**。在右侧下拉选语言（芬兰语/英语/瑞典语/中文），点击按钮，**允许浏览器使用麦克风**。识别结果与字幕桥一样自动翻译、保存。
- 两条通道可以同时用，结果都汇入同一个字幕流。

### ④ 两个面板（互不影响）

**左：字幕流**
- 每一行显示 `[时间] 原文` + 中文翻译。
- 按钮：**💾 保存翻译记录**（TXT）、**导出 SRT 字幕**（可挂到录播视频上）、**导出 Word**。

**右：课堂 AI 问答与笔记**
- **问 AI**：输入问题，AI 基于这节课的全部原文回答（不跑题）。
- **提取术语**：自动找出本课专业术语并译成中文，同时存进课程术语表。
- **✨ AI 整理**：把整节课整理成结构化笔记（**保留原文**，只增不改）。
- **我的笔记**：自己随手记，AI 永远不会动它；点 **保存笔记到课程** 随课保存。
- **课程术语表**：翻译/问答自动采用这些术语的固定译法，前后一致。可手动添加（如 `Mitokondrio → 线粒体`）、点击 × 删除、**导出 Anki CSV** 背单词。

### ⑤ AI 服务设置

- **本地 Ollama（默认）**：免费、离线可用。默认已配置好（`http://ollama:11434` + qwen 模型），一般不用动。想要更小/更快可把模型改成 `qwen3:4b-instruct`。
- **云端 AI（可选）**：填入接口地址 + API Key + 模型名（如 `glm-4-flash`、`deepseek-chat`），点 **保存云端 AI**；或填好 Key 后点 **自动识别模型**，系统会列出可用模型并选一个合适的。
- 云端只用于「问 AI / 整理 / 术语」等一次性任务；**翻译仍走本地 Ollama 保证速度和免费**（云端失败也会自动回退本地）。
- Key 留空 = 全部功能用本地模型。

### ⑥ 存储管理（归档与复看）

- **分类筛选 / 显示已归档**：按分类查看课程。
- 每门课右侧按钮：
  - **归档 / 取消归档**：期末结课把课程收进归档，平时不打扰；
  - **切换**：一键切回某门旧课，双语字幕和笔记完整复现（含时间戳）；
  - **删除**：彻底删除该课程（不可恢复，谨慎）。
- **分类管理**：新建分类（如“期末复习”）；分类标签上的 ✏️ 重命名（课程和总结自动跟随）、🗑 删除（课程自动归入「未分类」，数据不丢）。
- **AI 总结**：下拉按分类筛选，**查看**展开全文，**删除**清理。
- **📖 导出复习册**：把当前筛选分类（或全部）的 AI 总结**和各课程的「我的笔记」**一键打包成一个 Markdown 复习册文件——按分类分节、按时间排序，期末复习直接读这一份。
- **📝 自测**：根据当前筛选的 AI 总结自动生成选择题（默认 5 题），可以在网页上直接作答、提交判分并查看正确答案；选完「全部总结」就是整学期的大自测。
- **学习统计**：每门课的词数、时长、术语数、笔记字数。
- **清空字幕日志**：只清临时日志，不影响课程。
- **清理测试数据**：一键删掉开发时的测试课程并清空日志，真实课程不受影响。

## 三、完整使用流程（听课 → 复习）

1. **课前**：新建课程（含分类）→ 打开实时字幕（`Win+Ctrl+L`）→ 确认 🟢 在线。
2. **课中**：专心听。字幕自动显示并保存；随手记笔记随时保存。
3. **课间**：点 **✨ AI 整理** → 选分类 → **💾 保存总结到分类**；术语不懂就点 **提取术语** 或手动加入术语表。
4. **课后**：⑥ 里导出 Markdown 或 Word 复习；搜索关键词快速回看某段；**期末**：在 ⑥ 的 AI 总结区选好分类（或“全部总结”）→ 点 **📖 导出复习册**，把整学期笔记打包成一份 Markdown 复习册；再点 **📝 自测** 当场出题检验掌握程度，配合 Anki 术语表冲刺。

## 四、常见问题（FAQ）

**Q1：网页打开后什么都没有，字幕不动？**
按顺序检查：① 网页右上角服务灯（应显示 `ready`）；② 字幕桥灯 —— 🟡 就按 `Win+Ctrl+L` 打开字幕窗口；🔴 就双击 `start-captions.bat`；③ 确认字幕窗口有内容在滚动（先给电脑放一段英文视频测试）。

**Q2：实时字幕识别不出芬兰语？**
Windows 实时字幕不支持芬兰语。改用网页 ③ 的 **🎤 浏览器语音识别**，语言选「芬兰语」，使用 Chrome 或 Edge 并允许麦克风即可。

**Q3：翻译太慢 / 卡住？**
本地 Ollama 首段有时要等模型预热（几秒），之后就快了。如果持续很慢：检查电脑内存/显存占用；或在 ⑤ 把本地模型换成更小的（如 `qwen3:4b-instruct`）；翻译要求更快可选用云端 API 只给整理任务，翻译仍走本地。

**Q4：字幕桥总是离线，怎么彻底解决？**
`start-captions.bat` 自带崩溃自动重启（最多重试 5 次）。长期离线时看 `bridge/bridge.log` 的最后几行判断原因（丢给技术人员或按文档自查）。桥在等待窗口时会显示 🟡，不是故障。

**Q5：术语每次翻译不一样，怎么办？**
把术语手动加进课程术语表（如 `Mitokondrio → 线粒体`），之后所有翻译、问答都会用这个固定译法。提取术语按钮可以自动收集。

**Q6：AI 整理会覆盖我的笔记吗？**
不会。AI 整理是独立的输出；「我的笔记」只有你自己能改，课程里的 AI 永远不会动它。

**Q7：D 盘容量报警（红色警告条）怎么办？**
Docker 的数据盘在 D 盘，写满会导致服务崩溃。立即：删除不需要的旧课程 / 清空字幕日志，或把课程导出 Markdown/Word 后删除，再刷新页面。

**Q8：数据存在哪里？怎么备份？**
课程、字幕、术语、总结都存在 Docker 数据卷里（不占 C 盘）。备份：网页导出 Markdown/Word/CSV；彻底清理：`docker compose down -v`（会删光所有数据，慎用）。

**Q9：怎么更新到新版本？**
启动器启动时会自动对比 GitHub 上的版本号，发现新版会弹窗提示。更新方式：获取最新代码 → 重新双击 `install.bat`（覆盖安装，数据不动）。

**Q10：端口 8000 被占用 / 网页打不开？**
检查 Docker 是否在运行；`docker compose ps` 看容器状态；改端口需修改 `docker-compose.yml` 里的端口映射后重启。

**Q11：内存/显存不够用？**
听课时关掉其他大程序；本地模型选最小的（`qwen3:4b-instruct`）；翻译以外的智能功能（问 AI/整理）改用云端 API，把负担移到云端。

**Q12：清理测试数据按钮是干嘛的？**
开发过程会留下名为 Search、CatSession 等测试课程；点它一键清掉这些垃圾课程和日志，真实课程不受影响。建议每学期开学点一次。

## 五、故障排查速查表

| 症状 | 首选处理 |
|---|---|
| 服务灯显示 `backend unreachable` | 开 Docker Desktop → 双击 `start.bat` |
| 🟡 等待字幕窗口 | `Win+Ctrl+L` 打开实时字幕并保持可见 |
| 🔴 桥离线 | 双击 `start-captions.bat`，或先用 ③ 浏览器语音识别顶班 |
| 没声音但有字幕 | 正常：识别来自系统，不依赖本机音量 |
| 翻译是英文 | ⑤ 检查本地模型是否配置（`apiModel` 应为 qwen 系列） |
| 网页样式乱了/功能缺失 | `Ctrl+F5` 强制刷新（页面已禁用缓存） |
| 想换门课复看 | ⑥ 找到课程 → **切换** |

## 六、小贴士

- 字幕窗口最小化即可工作，不挡屏幕；嫌窗口碍事可以把它拖到屏幕角落。
- 浏览器语音识别（芬兰语）在 Chrome/Edge 效果最好。
- 同一时间**只开一个字幕桥**——重复启动会提示「another bridge instance is already running」并自动退出，这是防重复的正确行为。
- 术语表按课程隔离：不同课可以有不同的术语译法。
